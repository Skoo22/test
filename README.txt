STAY365 HOUSEKEEPING PLANNER V5.2

Host this folder on any static HTTPS site (GitHub Pages, Netlify, Cloudflare Pages, etc.).
Open the URL in Safari on iPhone -> Share -> Add to Home Screen.

Privacy model: the site serves the app code only. Room numbers, statuses, issues, tasks, reminders and history are stored in this browser/device using localStorage. A different person opening the same URL gets their own local copy. Do not put passwords, API keys or guest personal data into the app.

First launch opens Setup: enter your room numbers per floor and the two housekeeper names.

V5.2 improvements: a proper Tomorrow Planner workflow, room priorities, special room notes, a Tomorrow Ready state, historical workload estimates, tomorrow status on Home, morning briefing room notes, reminders, tappable Home summary cards, better cleaning/inspection timestamps, turnaround statistics, fixed re-clean history handling, and improved backup copying. V5.2 also migrates existing V5 data automatically.

Use Setup -> Backup regularly. Clearing Safari website data or changing browser/device can remove local data, so keep backups.

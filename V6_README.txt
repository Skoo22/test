Stay365 Housekeeping Planner V6 — Stable Polish Pass

Purpose:
Personal, single-user housekeeping/operations planner for Stay365.

V6 focus:
- iPhone/Safari touch and form-input polish
- iOS-friendly 16px form controls to avoid Safari zoom
- Stronger local snapshot safety on page hide/unload
- PWA/service-worker cache version bumped to V6
- No backend, guest database, employee accounts, or PMS integration added
- Existing V5.2 data model/workflow retained

Privacy model:
Operational data is intended to remain in the device browser's local storage. Hosting the static app does not create a shared server-side database.

Recommended use:
1. Host the static PWA over HTTPS.
2. Add it to the iPhone Home Screen.
3. Use the app normally.
4. Periodically use the app's existing backup/export mechanism if present.
